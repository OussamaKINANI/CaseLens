# CaseLens

CaseLens is an evidence-grounded clinical case review assistant.

It converts synthetic medical records into structured facts, retrieves relevant
clinical policy evidence, and prepares an auditable review for a human decision-maker.

## Safety

CaseLens is an educational demonstration. It uses synthetic data only and must
not be used for diagnosis, treatment decisions, or real patient information.

## Current status

The FastAPI backend foundation and automated testing environment are under development.
